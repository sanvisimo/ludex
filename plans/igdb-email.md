# La email a IGDB

Parte di «Licenze e donazioni» in [rilascio.md](rilascio.md): chiede a IGDB
se un link di donazioni rende commerciale l'uso della loro API. Bozza del
30/10/2026, da mandare dall'utente. La risposta va incollata qui sotto, e
riportata in [apps/api/CLAUDE.md](../apps/api/CLAUDE.md).

Prima di mandarla: il Client ID di Twitch, se si vuole, nel secondo
paragrafo; il numero di utenti, se si vuole dirlo.

## Da mandare

**To:** partner@igdb.com
**Subject:** Commercial use question – non-profit game library with optional
donations

Hello,

I'm Simone Sanvito, the developer of Ludex, a free, open-source (AGPL-3.0)
game library manager. Users import their libraries from Steam, GOG,
PlayStation and other stores, and Ludex helps them decide what to play next.
It is currently in a private beta and will open publicly soon at
https://ludex.sanvisimo.tech; the source code is public at
https://github.com/sanvisimo/ludex.

Ludex uses the IGDB API through my Twitch application to identify games and
fetch their metadata: titles, release dates, genres, themes, platforms,
related games and websites, with cover images loaded from images.igdb.com.
The data is cached in our own database and refreshed periodically, within the
API rate limits. IGDB is credited on our credits page, and each game page
links to the matching IGDB page.

Ludex is non-profit: there are no ads, no paid features and no
subscriptions, and user data is not sold. I would like to add an optional
"support the project" link for one-off donations (via Ko-fi), only to help
cover hosting costs.

Before enabling it, I'd like to ask:

1. Would accepting voluntary donations make this a commercial use of the IGDB
   API?
2. If so, what would a commercial agreement involve for a project of this
   size?
3. Are there specific attribution requirements I should meet?

If it helps, I'm happy to give you access to the beta or send screenshots.

Thank you for your time and for the great work on IGDB.

Best regards,
Simone Sanvito
