# La email a IGDB

Parte di «Licenze e donazioni» in [rilascio.md](rilascio.md): chiede a IGDB
se un link di donazioni, o più avanti un abbonamento per l'AI, rende
commerciale l'uso della loro API. **Inviata dall'utente il 30/10/2026**, col
testo qui sotto. La risposta va incollata in fondo, e riportata in
[apps/api/CLAUDE.md](../apps/api/CLAUDE.md).

## Inviata

**To:** partner@igdb.com
**Subject:** Commercial use question – non-profit game library with optional
donations

Hello,

I'm Simone Sanvito, the developer of Ludex, a free, open-source (AGPL-3.0)
game library manager. Users import their libraries from Steam, GOG,
PlayStation and other stores, and Ludex helps them decide what to play next.
It is currently in a private beta and will open publicly soon at
https://ludex.sanvisimo.tech; the source code is public at
https://github.com/sanvisimo/ludex.

Ludex uses the IGDB API through my Twitch application (client_id: quello di
`IGDB_CLIENT_ID`) to identify games and fetch their metadata: titles,
release dates, genres, themes, platforms, related games and websites, with
cover images loaded from images.igdb.com. The data is cached in our own
database and refreshed periodically, within the API rate limits. IGDB is
credited on our credits page, and each game page links to the matching IGDB
page.

Ludex is non-profit today: there are no ads, no paid features and no
subscriptions, and user data is not sold. Two things may change:

- soon, an optional link for one-off donations (via Ko-fi), only to help
  cover hosting costs;
- later, possibly an optional paid subscription for AI-based
  recommendations, to cover the cost of the language model. The rest of Ludex
  would stay free.

Before going ahead, I'd like to ask:

1. Would voluntary donations make this a commercial use of the IGDB API?
2. Would an optional paid subscription for AI features (which would also use
   IGDB data) require a commercial agreement, and what would that involve for
   a project of this size?
3. Are there specific attribution requirements I should meet?

If it helps, I'm happy to give you access to the beta or send screenshots.

Thank you for your time and for the great work on IGDB.

Best regards,
